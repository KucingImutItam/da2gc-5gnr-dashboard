# DA2GC 5G NR Radio Network Planning Dashboard

Interactive Streamlit research prototype for 3.5 GHz DA2GC / IFC planning. It includes:
- Editable link-budget and capacity inputs
- FSPL baseline calculation
- Coverage and capacity site dimensioning
- Interactive route map and indicative station/coverage circles
- CSV import for externally generated ITU-R P.528 basic transmission-loss data
- CSV exports and technical assumptions/validation checklist

## Run locally

Python 3.10+ recommended.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy online (Streamlit Community Cloud)

1. Create a GitHub repository and upload `app.py`, `requirements.txt`, and this README.
2. Sign in to Streamlit Community Cloud using GitHub.
3. Create a new app, choose the repository and `app.py`, then deploy.
4. Share the resulting app URL.

This deployment step requires the user's own GitHub/Streamlit account. This package does not deploy itself or create a hosted URL.

## Important model limitations

- FSPL is calculated in the app as `32.45 + 20 log10(f_MHz) + 20 log10(d_km)`.
- ITU-R P.528 is **not** implemented natively. Upload a CSV with `distance_km` and `basic_transmission_loss_db` generated by a validated implementation. Document the implementation/version, frequency, antenna heights, polarization and time percentage.
- The default threshold is a generic received-power threshold, not automatically equivalent to SS-RSRP or SINR.
- The route map is illustrative; station positions are not optimized. Route interpolation is straight-line and should be replaced by real route/GIS data for publication-grade results.
- Capacity estimates are first-order. Use defensible spectral efficiency, NR TDD/PRB configuration, MIMO, overhead, Doppler/mobility, and traffic assumptions.
- Spectrum allocation, interference, and aviation/regulatory feasibility at 3.5 GHz must be independently assessed.

## P.528 CSV format

```csv
distance_km,basic_transmission_loss_db,time_percentage,frequency_mhz,source
10,REPLACE_WITH_VALIDATED_OUTPUT,5,3500,software/version and run details
20,REPLACE_WITH_VALIDATED_OUTPUT,5,3500,software/version and run details
```

Do not use placeholder values as P.528 results in a paper.
